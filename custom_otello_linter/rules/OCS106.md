# OCS106. Decorator @selectoleted or selectoleted(...) should not be presented

`@selectoleted` and `selectoleted(...)` are selectolet markers for **local** runs (`make e2e-run`). They must not be committed (same idea as `@vedro.only` / VDR101).

Use them only on a feature branch while developing; remove before merge to master.

### Where the marker works (selectolet)

- `@selectoleted` on a **top-level** class or function (scenario, context, page object, helper).
- `Name = selectoleted(...)` at **module level** in `schemas/` or `dicts/`.

Not supported: decorators on scenario steps, assignments inside a class body.
